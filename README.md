# Mary’s Songs

Интерактивный музыкальный сайт певицы Mary: четыре трека, пять визуальных концепций, карусель, анимации и адаптивная мобильная версия.

## Готовая версия для любого статического хостинга

Папка **`static/`** содержит готовый сайт: HTML, CSS, JavaScript, иконку, изображения и MP3.
После каждого успешного деплоя GitHub Pages workflow автоматически обновляет эту папку в `main`.
Служебный коммит с изменениями только в `static/` не запускает новый деплой.

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте.
2. Перенесите **содержимое** `static/` в корневую папку сайта на хостинге (обычно `public_html/`).
3. `index.html`, `_next/`, `tracks/` и изображения должны оказаться рядом в корне сайта.
4. Подключите домен и HTTPS в панели провайдера.

Сборка предназначена для корня домена, например `https://your-domain.ru/`.
Node.js и сервер Next.js на хостинге не нужны.
Открывать сайт нужно через HTTP(S), а не двойным щелчком по HTML-файлу.
Ссылки на Яндекс Музыку открывают внешний сервис.

Также готовый ZIP **marys-songs-static** доступен в **Actions → успешный запуск → Artifacts**.
Если скачивать репозиторий, дождитесь завершения задания **save-static**.
Если во время деплоя появились новые изменения исходников, папку обновит следующий актуальный деплой.

## Сборка вручную

Требуется Node.js 22.13 или новее.

```bash
npm ci
npm run build:static
```

Команда подготавливает медиа, собирает сайт без префикса `/marys-songs`, проверяет файлы и обновляет `static/`.
При ошибке сборки или проверки предыдущая папка сохраняется.
Медиа берутся из `public/`, затем из сохранённой `static/`; недостающие файлы скачиваются с исходного сайта.
Чтобы заменить уже существующее изображение или трек, положите новую версию по соответствующему пути в `public/` перед сборкой и сохраните обновлённую `static/` в репозитории.

## GitHub Pages

Сайт автоматически собирается и публикуется после обновления исходников в ветке `main`.
Деплой создаёт две сборки: переносимую в `static/` и версию с префиксом `/marys-songs` в `out/` для GitHub Pages.
Публичный адрес: https://wildwestwild.github.io/marys-songs/

## Локальный запуск

```bash
npm ci
npm run media:prepare
npm run dev
```
